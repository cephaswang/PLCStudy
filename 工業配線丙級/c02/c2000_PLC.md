# 丙級工業配線 第二題 自動台車分料系統 — 三菱 PLC(FX 系列)LD 程式

> 本版為**修正整理版**,取代先前對話中較繁雜的寫法。邏輯已逐項對照動作說明驗證。

---

## 一、I/O 分配表

| 輸入 | 元件 | 說明 | 輸出 | 元件 | 說明 |
|---|---|---|---|---|---|
| X0 | PB1 | 往崗位 1 | Y0 | MC1 | 正轉(台車向右) |
| X1 | PB2 | 往崗位 2 | Y1 | MC2 | 反轉(台車向左) |
| X2 | PB3 | 往崗位 3 | Y2 | PL1 | 正轉指示燈 |
| X3 | LS1 | 崗位 1 極限開關(a 接點) | Y3 | PL2 | 反轉指示燈 |
| X4 | LS2 | 崗位 2 極限開關(a 接點) | Y4 | PL3 | 異常指示燈 |
| X5 | LS3 | 崗位 3 極限開關(a 接點) | Y5 | BZ | 蜂鳴器 |
| X6 | OL | 過載保護(跳脫時 ON) | | | |
| X7 | COS1-1 | 切換開關位置 1 | | | |
| X10 | COS1-2 | 切換開關位置 2 | | | |

### 內部繼電器

| 元件 | 用途 |
|---|---|
| M0 | 記憶「正轉,目標崗位 2」(LS1 → PB2) |
| M1 | 記憶「反轉,目標崗位 2」(LS3 → PB2) |
| M3 | 正轉到達崗位 2 的停止訊號 |
| M4 | 反轉到達崗位 2 的停止訊號 |

---

## 二、設計邏輯

**正轉 Y0 起動條件**:`LS1·PB2` + `LS1·PB3` + `LS2·PB3`
**正轉停止條件**:LS3 動作;或「目標為崗位 2(M0)且 LS2 動作」

**反轉 Y1 起動條件**:`LS2·PB1` + `LS3·PB1` + `LS3·PB2`
**反轉停止條件**:LS1 動作;或「目標為崗位 2(M1)且 LS2 動作」

**其他**
- Y0、Y1 互鎖,OL 動作(X6)時一律斷電。
- 起動需 COS1 在位置 1(X7)。
- 同崗位按同號按鈕(如 LS1 按 PB1)不在起動條件內,所以「無任何動作」。
- 中途經過 LS2 時(LS1→PB3、LS3→PB1)因 M0、M1 未成立,不會停止,符合「繼續轉動」。

## 三、梯形圖

```
(* Rung 0 正轉到達崗位2 停止訊號 *)
|  M0   X4                                      |
+--| |---| |------------------------------( M3 )-+

(* Rung 1 反轉到達崗位2 停止訊號 *)
|  M1   X4                                      |
+--| |---| |------------------------------( M4 )-+

(* Rung 2 M0 記憶:LS1 + PB2 *)
|  X3   X1                                       |
+--| |---| |--+--------+--|/|--|/|--|/|--( M0 )--+
|  M0          |        |  X4   X5   X6           |
+--| |---------+                                  |

(* Rung 3 M1 記憶:LS3 + PB2 *)
|  X5   X1                                       |
+--| |---| |--+--------+--|/|--|/|--|/|--( M1 )--+
|  M1          |        |  X4   X3   X6           |
+--| |---------+                                  |

(* Rung 4 正轉 MC1 *)
|  X3   X1                                                           |
+--| |---| |--+                                                       |
|  X3   X2    |                                                      |
+--| |---| |--+--+--[ X7 ]--+--|/|--|/|--|/|--|/|--|/|--( Y0 )------+
|  X4   X2    |  |          |   Y1   X6   X5   M3                   |
+--| |---| |--+  |   Y0     |                                       |
                  +---| |---+                                       |

(* Rung 5 反轉 MC2 *)
|  X4   X0                                                           |
+--| |---| |--+                                                       |
|  X5   X0    |                                                      |
+--| |---| |--+--+--[ X7 ]--+--|/|--|/|--|/|--|/|--|/|--( Y1 )------+
|  X5   X1    |  |          |   Y0   X6   X3   M4                   |
+--| |---| |--+  |   Y1     |                                       |
                  +---| |---+                                       |

(* Rung 6~7 指示燈 *)
|  Y0                                  |
+--| |---------------------------( Y2 )-+
|  Y1                                  |
+--| |---------------------------( Y3 )-+

(* Rung 8 OL 動作且 COS1 在位置1 → BZ 響 *)
|  X6   X7                               |
+--| |---| |-----------------------( Y5 )-+

(* Rung 9 COS1 切位置2 → BZ 停、PL3 亮 *)
|  X6   X10                              |
+--| |---| |-----------------------( Y4 )-+
```

> 註:Rung 4、5 中 `X7` 與 `Y0`/`Y1` 自保持的並聯關係,在 GX Works 以指令表輸入後會自動轉為正確圖形,請以下方指令表為準。

## 四、指令表(可直接輸入 GX Works)

```
(* ---- 停止訊號(須放在 M0、M1 之前) ---- *)
0   LD   M0
1   AND  X4
2   OUT  M3          // 正轉到崗位2停止

3   LD   M1
4   AND  X4
5   OUT  M4          // 反轉到崗位2停止

(* ---- 目標記憶 ---- *)
6   LD   X3
7   AND  X1
8   OR   M0
9   ANI  X4
10  ANI  X5
11  ANI  X6
12  OUT  M0          // LS1+PB2:正轉目標崗位2

13  LD   X5
14  AND  X1
15  OR   M1
16  ANI  X4
17  ANI  X3
18  ANI  X6
19  OUT  M1          // LS3+PB2:反轉目標崗位2

(* ---- 正轉 MC1(向右) ---- *)
20  LD   X3
21  AND  X1
22  LD   X3
23  AND  X2
24  ORB
25  LD   X4
26  AND  X2
27  ORB              // LS1·PB2 + LS1·PB3 + LS2·PB3
28  AND  X7          // COS1 位置1
29  OR   Y0          // 自保持
30  ANI  Y1          // 互鎖
31  ANI  X6          // OL
32  ANI  X5          // LS3 停止
33  ANI  M3          // 崗位2 停止(僅目標為2時)
34  OUT  Y0

(* ---- 反轉 MC2(向左) ---- *)
35  LD   X4
36  AND  X0
37  LD   X5
38  AND  X0
39  ORB
40  LD   X5
41  AND  X1
42  ORB              // LS2·PB1 + LS3·PB1 + LS3·PB2
43  AND  X7
44  OR   Y1
45  ANI  Y0
46  ANI  X6
47  ANI  X3          // LS1 停止
48  ANI  M4
49  OUT  Y1

(* ---- 指示燈 ---- *)
50  LD   Y0
51  OUT  Y2          // PL1
52  LD   Y1
53  OUT  Y3          // PL2

(* ---- 異常處理 ---- *)
54  LD   X6
55  AND  X7
56  OUT  Y5          // OL 動作、COS1 位置1 → BZ 響
57  LD   X6
58  AND  X10
59  OUT  Y4          // COS1 位置2 → BZ 停、PL3 亮
60  END
```

## 五、動作驗證

| 初始位置 | 操作 | 結果 |
|---|---|---|
| 通電 | — | Y0~Y5 全 OFF |
| LS1 | PB1 | 無動作 |
| LS1 | PB2 | M0 ON → Y0 ON(PL1 亮)→ 到 LS2:M3 ON,Y0 OFF |
| LS1 | PB3 | Y0 ON → 經 LS2 不停(M0 未成立)→ LS3 停止 |
| LS2 | PB1 | Y1 ON(PL2 亮)→ LS1 停止 |
| LS2 | PB2 | 無動作 |
| LS2 | PB3 | Y0 ON → LS3 停止 |
| LS3 | PB1 | Y1 ON → 經 LS2 不停 → LS1 停止 |
| LS3 | PB2 | M1 ON → Y1 ON → 到 LS2:M4 ON,Y1 OFF |
| LS3 | PB3 | 無動作 |
| 運轉中 OL 動作 | — | Y0、Y1 OFF,台車停止;COS1 在位置 1 → BZ(Y5)響 |
| COS1 切位置 2 | — | BZ 停響,PL3(Y4)亮 |

---

## 六、注意事項

1. **接點極性**:若實機 OL 為 b 接點(跳脫時斷開),X6 邏輯需反相(`LD X6` → `LDI X6`,其餘 `ANI X6` → `AND X6`)。LS 若接 b 接點亦同理。
2. **八進位編號**:FX 系列 X、Y 為八進位,X7 之後是 X10,沒有 X8、X9。
3. **指令順序**:M3、M4 的 rung 必須放在 M0、M1 之前,才能在同一掃描週期內取得停止訊號。
4. **GX Works 轉換**:以指令表輸入後可自動轉為梯形圖。
5. **競賽/考試用途**:實際檢定為配線與故障檢修,此 PLC 程式僅作邏輯練習與動作驗證參考。
