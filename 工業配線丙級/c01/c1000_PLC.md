# 第一題 單相感應電動機順序起動控制：三菱 PLC LD 程式

- 適用機種：三菱 FX 系列（FX3U / FX3G / FX5U 相容寫法），GX Works2 / GX Works3 可直接輸入。
- 計時器：T1～T3 為 100 ms 單位，`K30` = 3 秒，請依題目實際時間修改。
- 邏輯與先前的「動作模擬器」一致。

---

## 1. I/O 分配

### 輸入

| 位址 | 元件 | 說明 | 接點 |
|------|------|------|------|
| X0 | LS1 | 限制開關 1 | a 接點，動作 = ON |
| X1 | LS2 | 限制開關 2 | a 接點，動作 = ON |
| X2 | COS1 位置 1 | 自動順序控制 | a 接點，切到位置 1 = ON |
| X3 | COS1 位置 2 | 手動順序控制 | a 接點，切到位置 2 = ON |
| X4 | PB1 | 按鈕開關 1 | a 接點 |
| X5 | PB2 | 按鈕開關 2 | a 接點 |
| X6 | PB3 | 按鈕開關 3 | a 接點 |
| X7 | OL | 積熱電驛 | b 接點，**正常 = ON，跳脫 = OFF**（斷線也會安全停機） |

### 輸出

| 位址 | 元件 | 說明 |
|------|------|------|
| Y0 | MC1 | M1 電動機 |
| Y1 | MC2 | M2 電動機 |
| Y2 | MC3 | M3 電動機 |
| Y3 | MC4 | M4 電動機 |
| Y4 | PL1 | 黃色指示燈（隨 MC2） |
| Y5 | PL2 | 黃色指示燈（隨 MC3） |
| Y6 | PL3 | 紅色指示燈（隨 MC4） |
| Y7 | BZ | 蜂鳴器 |

### 內部元件

| 位址 | 說明 |
|------|------|
| M1 | 手動：M2 運轉（MC2） |
| M2 | 手動：M3 運轉（MC3） |
| M3 | 手動：M4 運轉（MC4） |
| M10 | 自動：M2 運轉（MC2） |
| M11 | 自動：M3 運轉（MC3） |
| M12 | 自動：M4 運轉（MC4） |
| M13 | 自動：BZ 響 |
| T1 | 計時器 T1（K30 = 3 s） |
| T2 | 計時器 T2（K30 = 3 s） |
| T3 | 計時器 T3（K30 = 3 s） |

## 2. 梯形圖（LD）

> `| |` = a 接點，`|/|` = b 接點，`( )` = 線圈，`[T1 K30]` = 計時線圈。並聯分支以 `+` 向下接出。

### Rung 0　MC1：LS1 動作且 OL 正常

```
      X0      X7
 +----| |-----| |---------------------------( Y0 )
```

### Rung 1　手動：M4 運轉（M3）

```
      M2      X6          X3
 +----| |-----| |----+----| |---------------( M3 )
 |                   |
 |    M3             |
 +----| |------------+
```

### Rung 2　手動：M3 運轉（M2）

```
      M1      X5          X3      X6
 +----| |-----| |----+----| |-----|/|-------( M2 )
 |                   |
 |    M2             |
 +----| |------------+
```

### Rung 3　手動：M2 運轉（M1）

```
      X4                  X3      X5      M2      M3
 +----| |------------+----| |-----|/|-----|/|-----|/|---( M1 )
 |                   |
 |    M1             |
 +----| |------------+
```

> **順序很重要**：Rung 1 → Rung 2 → Rung 3 必須依此順序排列。
> PLC 由上往下掃描，按 PB2 時 Rung 2 要先讀到「M1 仍為 ON」才能啟動 M2，隨後 Rung 3 才讓 M1 斷開。
> 順序顛倒的話，M2 會啟動不了。

### Rung 4～6　自動：T1、T2、T3 計時

```
      X2      X1
 +----| |-----| |------------------------[ T1 K30 ]

      T1
 +----| |--------------------------------[ T2 K30 ]

      T2
 +----| |--------------------------------[ T3 K30 ]
```

### Rung 7～10　自動：各段輸出

```
      X2      X1      T1
 +----| |-----| |-----|/|-----------------( M10 )     MC2 段：T1 到時前

      T1      T2
 +----| |-----|/|-------------------------( M11 )     MC3 段：T1 到時後、T2 到時前

      T2      T3
 +----| |-----|/|-------------------------( M12 )     MC4 段：T2 到時後、T3 到時前

      T3
 +----| |---------------------------------( M13 )     BZ 段：T3 到時後
```

> LS2 復歸時 T1 失電，T2、T3 隨後失電（T2 的線圈由 T1 接點驅動），M10～M13 全部復歸，符合「LS2 復歸 → MC2～MC4、燈、BZ 全復歸」。

### Rung 11～14　輸出（手動 OR 自動）

```
      M1
 +----| |-----+------------------------( Y1 )     MC2
 |            |
 |    M10     |
 +----| |-----+

      M2
 +----| |-----+------------------------( Y2 )     MC3
 |            |
 |    M11     |
 +----| |-----+

      M3
 +----| |-----+------------------------( Y3 )     MC4
 |            |
 |    M12     |
 +----| |-----+

      M13
 +----| |----------------------------( Y7 )       BZ
```

### Rung 15～17　指示燈與結束

```
      Y1
 +----| |--------------------------------( Y4 )     PL1

      Y2
 +----| |--------------------------------( Y5 )     PL2

      Y3
 +----| |--------------------------------( Y6 )     PL3

 +---------------------------------------[ END ]
```

## 3. 指令表（IL）

可直接在 GX Works 的「指令表」模式輸入。

```
0   LD    X0            // LS1
1   AND   X7            // OL 正常
2   OUT   Y0            // MC1

3   LD    M2            // 手動：PB3 啟動 M4
4   AND   X6
5   OR    M3
6   AND   X3
7   OUT   M3

8   LD    M1            // 手動：PB2 啟動 M3
9   AND   X5
10  OR    M2
11  AND   X3
12  ANI   X6
13  OUT   M2

14  LD    X4            // 手動：PB1 啟動 M2
15  OR    M1
16  AND   X3
17  ANI   X5
18  ANI   M2
19  ANI   M3
20  OUT   M1

21  LD    X2            // 自動：T1 計時
22  AND   X1
23  OUT   T1  K30
26  LD    T1            // T2 計時
27  OUT   T2  K30
30  LD    T2            // T3 計時
31  OUT   T3  K30

34  LD    X2            // 自動：MC2 段
35  AND   X1
36  ANI   T1
37  OUT   M10
38  LD    T1            // 自動：MC3 段
39  ANI   T2
40  OUT   M11
41  LD    T2            // 自動：MC4 段
42  ANI   T3
43  OUT   M12
44  LD    T3            // 自動：BZ 段
45  OUT   M13

46  LD    M1            // 輸出 MC2
47  OR    M10
48  OUT   Y1
49  LD    M2            // 輸出 MC3
50  OR    M11
51  OUT   Y2
52  LD    M3            // 輸出 MC4
53  OR    M12
54  OUT   Y3
55  LD    M13           // 輸出 BZ
56  OUT   Y7

57  LD    Y1            // PL1
58  OUT   Y4
59  LD    Y2            // PL2
60  OUT   Y5
61  LD    Y3            // PL3
62  OUT   Y6

63  END
```

## 4. 動作對照與驗證

| 動作說明 | PLC 行為 |
|----------|----------|
| 通電後全部停止 | M、T 皆為 OFF，Y0～Y7 = OFF |
| LS1 動作 / 復歸 | X0 ON → Y0 ON；X0 OFF → Y0 OFF |
| 手動（X3 ON）按 PB1 | M1 自保 → Y1、Y4 ON |
| 手動 按 PB2 | M2 啟動、M1 斷開 → Y2、Y5 ON；Y1、Y4 OFF |
| 手動 按 PB3 | M3 啟動、M2 斷開 → Y3、Y6 ON；Y2、Y5 OFF |
| 手動 LS1 復歸 | 只有 Y0 OFF，其餘不變 |
| 自動（X2 ON）LS2 動作 | M10 ON → Y1、Y4 ON，T1 計時 |
| 自動 T1 到時 | M10 OFF、M11 ON → Y2、Y5 ON，T2 計時 |
| 自動 T2 到時 | M11 OFF、M12 ON → Y3、Y6 ON，T3 計時 |
| 自動 T3 到時 | M12 OFF、M13 ON → Y3、Y6 OFF，Y7（BZ）ON |
| 自動 LS2 復歸 | T1～T3、M10～M13 全 OFF → Y1～Y7 全 OFF |
| 自動 LS1 復歸 | 只有 Y0 OFF，其餘不變 |
| OL 動作 | X7 OFF → 只有 Y0 OFF，其餘不變 |

## 5. 注意事項與假設

1. **OL 接 b 接點**：若現場是 a 接點，將 Rung 0 的 `AND X7` 改為 `ANI X7`。
2. **PB 互鎖**：假設 PB2 需在 M2 運轉後才有效、PB3 需在 M3 運轉後才有效，對應線路圖的 MC 自保與互鎖接點。若題目允許任意順序按，可移除相關的 `AND M1` / `AND M2`。
3. **COS1 切換**：切換時 X2 / X3 變化會使另一組控制電路失電，順序狀態自動歸零。
4. **掃描順序**：手動三個 rung 必須依 M3 → M2 → M1 的順序（見 Rung 3 說明）。
5. **輸出保護**：實際接線時，MC2～MC4 的線圈建議加上互鎖與突波吸收；輸出點 COM 與電源規格依機種手冊確認。
6. **PL / BZ 同動作**：PL1～PL3 是以 Y1～Y3 的接點驅動，等同線圈同時動作。若指示燈電壓與 MC 線圈不同，須分開 COM 群組。
