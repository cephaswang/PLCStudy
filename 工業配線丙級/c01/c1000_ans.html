第一題 單相感應電動機順序起動控制：動作模擬器

丙級 工業配線 A-故障檢修（01300-104301A）。依動作說明編寫，可手動操作各輸入元件並觀察 MC、指示燈、BZ 動作。

輸入元件

秒（每個計時器設定值）
PB 為按住動作的按鈕（滑鼠按住或手指按住）；LS1、LS2、OL 為保持型，點一下切換。

輸出狀態

PL1 黃
PL2 黃
PL3 紅
BZ

目前動作

OL 已動作：僅 MC1 復歸，其餘 MC、指示燈及 BZ 狀態不變。

動作檢驗（依題意自動測試）

    事件紀錄

      故障模擬：點選 S 點使該點斷路

      對應「檢測開關位置」圖的 S1～S10。點一下使該點斷路（再點一下接通），然後回上方照動作說明操作，觀察哪裡不對。

      如何識別故障

      1. 逐項試動作：通電後依序試：LS1 動作（MC1）→ COS1 位置 2 手動 PB1、PB2、PB3 → COS1 位置 1 自動 LS2 動作並等 T1、T2、T3 → LS2、LS1 復歸 → OL。記下哪一步與動作說明不同。
      2. 先分主線路／控制線路：MC 有吸入、指示燈亮，但電動機不轉 → 故障在主線路（S8、S9、S10）。MC 沒吸入或燈不亮、順序停住 → 故障在控制線路（S1～S7）。
      3. 從停住的那一步往回推：自動順序每一級由前一級的計時接點推動：R → T1 → T2 → T3。停在哪一級，就檢查該級的線圈支路與接點支路。
      4. 量測：通電電壓法——以 23 號線（負載共同端）為共同點，從 2 號線往後逐點量，220V 變 0V 處即斷點。斷電電阻法——壓住 LS 或按住 PB，量該段是否導通。主線路則量 TB2 各電動機端子電壓。
      5. 填答：只有 S8～S10 斷 →(A)；只有 S1～S7 斷 →(B)；兩邊都有 →(C)；都沒有 →(D)。
      S 點落點是依檢測圖與線路圖判讀的簡化模型，與實物可能略有差異。

      S 點位置・症狀・量測

      點位置斷路時症狀量測／識別

      採用的控制邏輯

      MC1 = 電源 ∧ LS1 ∧ OL 正常（與 COS1 位置無關，OL 只影響 MC1）。
      手動（COS1=2）：PB1 → MC2/PL1；PB2 → MC2 斷、MC3/PL2；PB3 → MC3 斷、MC4/PL3；LS2 與 T 不影響。
      自動（COS1=1）：LS2 動作 → MC2/PL1、T1 計時；T1 到 → MC3/PL2、T2；T2 到 → MC4/PL3、T3；T3 到 → MC4 斷、BZ 響；LS2 復歸 → MC2~MC4、燈、BZ 全復歸。
      假設：PB2 需在 MC2 動作後有效，PB3 需在 MC3 動作後有效（對應線路圖的 MC 自保與互鎖接點）；切換 COS1 時另一組控制電路失電，順序狀態歸零。
