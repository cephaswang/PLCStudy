# 第六題 三相感應電動機順序啟閉控制：三菱 PLC 梯形圖（LD）

適用 FX 系列。計時器 T1、T2 以 0.1 秒為單位，`K30` 代表 3 秒，可自行調整。

## 一、I/O 配置

| 輸入 | 元件 | 說明 |
|---|---|---|
| X0 | PB1 | 啟動按鈕（a 接點） |
| X1 | PB2 | 停止按鈕（a 接點） |
| X2 | COS1 位置 1 | 正常操作位置 |
| X3 | COS1 位置 2 | 異常消音位置 |
| X4 | OL1 | 跳脫時為 ON |
| X5 | OL2 | 跳脫時為 ON |
| X6 | OL3 | 跳脫時為 ON |

| 輸出 | 元件 | 說明 |
|---|---|---|
| Y0 | MC1 | M1 電動機 |
| Y1 | MC2 | M2 電動機 |
| Y2 | MC3 | M3 電動機 |
| Y3 | PL1 | M1 運轉燈（紅） |
| Y4 | PL2 | M2 運轉燈（紅） |
| Y5 | PL3 | 異常消音燈（綠） |
| Y6 | PL4 | M3 運轉燈（綠） |
| Y7 | BZ | 蜂鳴器 |

| 內部元件 | 說明 |
|---|---|
| M0 | OL 任一動作 |
| M1 | 允許運轉（COS1 在位置 1 且 OL 全正常） |
| T1、T2 | 計時器，K30 = 3 秒 |

## 二、梯形圖

```
Rung 0：OL 任一動作
 X4 ──┬──┤ ├──┬──────────────────────( M0 )
 X5 ──┤        │
 X6 ──┘        │

Rung 1：允許運轉
 X2     M0
──┤ ├───┤/├────────────────────────( M1 )

Rung 2：MC1（啟動、自保、停止）
 X0     M1     Y1     Y2
──┤ ├───┤ ├───┤/├───┤/├──┬──┬────┤ ├───┤/├──( Y0 )
 Y0                      │  M1    X1
──┤ ├────────────────────┘

Rung 3：T1 啟動時與停止時各計時一次（Y0 與 Y1 狀態不同時計時）
 Y0     Y1
──┤ ├───┤/├──┬─────────────────────( T1 K30 )
 Y0     Y1   │
──┤/├───┤ ├──┘

Rung 4：T2 啟動時與停止時各計時一次（Y1 與 Y2 狀態不同時計時）
 Y1     Y2
──┤ ├───┤/├──┬─────────────────────( T2 K30 )
 Y1     Y2   │
──┤/├───┤ ├──┘

Rung 5：MC2
 T1     Y0
──┤ ├───┤ ├────────────────────────[ SET Y1 ]
 T1     Y0
──┤ ├───┤/├────────────────────────[ RST Y1 ]

Rung 6：MC3
 T2     Y1     Y0
──┤ ├───┤ ├───┤ ├───────────────────[ SET Y2 ]
 T2     Y1
──┤ ├───┤/├────────────────────────[ RST Y2 ]

Rung 7：運轉指示燈
 Y0 ──┤ ├──────────────────────────( Y3 )   PL1
 Y1 ──┤ ├──────────────────────────( Y4 )   PL2
 Y2 ──┤ ├──────────────────────────( Y6 )   PL4

Rung 8：異常顯示
 M0     X2
──┤ ├───┤ ├────────────────────────( Y7 )   BZ 響
 M0     X3
──┤ ├───┤ ├────────────────────────( Y5 )   PL3 亮

                                    [ END ]
```

## 四、動作對照

| 動作說明 | 程式對應 |
|---|---|
| 1. 通電後所有電動機停止 | Y0～Y2 初始為 OFF |
| 2. 按 PB1，M1 運轉，T1 計時 | Rung 2 讓 Y0 ON，Rung 3 因 Y0≠Y1 啟動 T1 |
| 3. T1 到，M2 加入，T2 計時，T1 斷電 | Rung 5 SET Y1，T1 因 Y0＝Y1 而斷電，Rung 4 因 Y1≠Y2 啟動 T2 |
| 4. T2 到，M3 加入，T2 斷電 | Rung 6 SET Y2，T2 因 Y1＝Y2 而斷電 |
| 5. 按 PB2，M1 停止，T1 計時 | X1 使 Y0 OFF，T1 因 Y0≠Y1 計時 |
| 6. T1 到，M2 停止，T2 計時 | Rung 5 RST Y1，T2 因 Y1≠Y2 計時 |
| 7. T2 到，M3 停止 | Rung 6 RST Y2 |
| 異常：OL 動作，依序停止，BZ 響 | M0 ON 使 M1 OFF，Y0 失去自保，走與 PB2 相同的停止順序，Y7 輸出 |
| COS1 切到位置 2，BZ 停響，PL3 亮 | X2 OFF、X3 ON，Y7 OFF、Y5 ON |

## 五、注意事項

- 本程式假設 OL 以 a 接點（動作時閉合）接入 PLC。若實際接 b 接點（正常時閉合），Rung 0 的 X4～X6 要改為 `LDI`、`ORI`，或在 Rung 0 前加反相處理。
- 若 PB2 實際接成 b 接點，Rung 2 的 `ANI X1` 要改為 `AND X1`。
- 啟動時 Rung 2 要求 `ANI Y1`、`ANI Y2`，目的是停止順序尚未結束時不接受 PB1，避免重新啟動時序錯亂。
- Rung 3、4 用「兩個狀態不同才計時」的寫法，同一個計時器同時負責啟動與停止兩段延時，計時器數量剛好是原題的 T1、T2 兩個。
