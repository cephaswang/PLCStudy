# 三相感應電動機 Y-△降壓起動控制（二）— 三菱 PLC 程式

適用機種：三菱 FX 系列（FX3U 等），GX Works2 / GX Works3

## 1. I/O 分配

### 輸入

| 位址 | 器具 | 說明 |
|---|---|---|
| X0 | PB1 | 接常閉（b 接點）。平時 X0=ON，按下變 OFF |
| X1 | PB2 | 常開（a 接點） |
| X2 | COS1 位置 1 | 位置 1 時 ON |
| X3 | COS1 位置 2 | 位置 2 時 ON |
| X4 | TH-RY | 接 97-98 常開接點，過載跳脫時 ON |

### 輸出

| 位址 | 器具 | 說明 |
|---|---|---|
| Y0 | MC1 | 電源 |
| Y1 | MC2 | △ 結線 |
| Y2 | MC3 | Y 結線 |
| Y3 | PL1 | Y 運轉（紅） |
| Y4 | PL2 | △ 運轉（紅） |
| Y5 | PL3 | 過載（黃） |
| Y6 | PL4 | 停止（綠） |
| Y7 | BZ | 蜂鳴器 |

### 內部元件

| 位址 | 說明 |
|---|---|
| M0 | 控制電源許可 |
| T0 | T1 延時（K50 = 5 秒，100ms 單位） |

## 4. 動作對照

| 情況 | 動作 |
|---|---|
| 通電待機 | COS1 在位置 1，M0 ON，PL4（Y6）亮 |
| 按 PB2 | Y0 自保持，T0 開始計時；Y2（MC3）動作，PL1 亮、PL4 熄 |
| T0 計時到 | Y2 先斷，Y1（MC2）再動作，PL1 熄、PL2 亮；Y1 與 Y2 互鎖 |
| 按住 PB1 | X0 變 OFF，M0 斷電，全部復歸、燈全熄；放開後 PL4 亮 |
| TH-RY 動作 | X4 ON，M0 失電，MC 全部復歸。COS1 在位置 1 時 BZ（Y7）響；切到位置 2 時 BZ 停、PL3（Y5）亮 |

## 5. 注意事項

- 若 PB1 實際接常開，把第 0 行的 `AND X0` 改成 `ANI X0`。
- 主電路的 MC2、MC3 建議另外加機械互鎖或常閉接點互鎖，不要只靠程式互鎖。
- 延時時間改 `K` 值即可（K10 = 1 秒）。
- Q 系列或 iQ-R 需把 X/Y 改成對應模組位址。
