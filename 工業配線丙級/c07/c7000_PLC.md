# 第七題　往復式送料機自動控制　三菱 PLC 梯形圖（LD）

適用：三菱 FX 系列（FX3U／FX3G／FX5U 皆可，GX Works2／GX Works3 輸入）。
時鐘 `M8013` 為 1 秒時鐘脈衝（0.5 秒亮、0.5 秒滅）。

---

## 一、I/O 分配表

### 輸入（X）

| 位址 | 器具 | 說明 | 接點型式 |
|---|---|---|---|
| X0 | PB1 | 異常復歸（FR 復歸、BZ 停響） | 常開 |
| X1 | PB2 | 起動 | 常開 |
| X2 | PB3 | 停止 | 常開 |
| X3 | PB4 | PL3 測試 | 常開 |
| X4 | LS1 | 行程開關 1 | 常開 |
| X5 | LS2 | 行程開關 2 | 常開 |
| X6 | OL | 過載（跳脫時接點閉合） | 常開 |

> 若實際 OL 使用常閉接點，把第 0、7～9 列的 `X6` 接點改成反相即可。

### 輸出（Y）

| 位址 | 器具 | 說明 |
|---|---|---|
| Y0 | MCF | 正轉電磁接觸器 |
| Y1 | MCR | 反轉電磁接觸器 |
| Y2 | PL1 | 綠燈：LS1 階段（T1 計時） |
| Y3 | PL2 | 綠燈：LS2 階段（T2 計時） |
| Y4 | PL3 | 紅燈：運轉／測試 |
| Y5 | PL4 | 黃燈：異常 |
| Y6 | BZ | 蜂鳴器 |

### 內部元件

| 元件 | 用途 |
|---|---|
| M0 | 運轉自保持（對應 X2 電驛） |
| M1 | 反轉狀態記憶（T1 到後 SET，T2 到後 RST） |
| M2 | 異常復歸記憶（對應 X1 電驛，按 PB1 後保持） |
| T0 | T1 限時（K30＝3 秒，100 ms 計時器） |
| T1 | T2 限時（K30＝3 秒） |
| M8013 | 1 秒時鐘（取代 FR 閃爍電驛） |

## 四、動作對照（驗證用）

| 動作說明 | 程式行為 |
|---|---|
| 通電後全停、指示燈全熄 | M0＝0，Y0～Y6 皆 OFF |
| 按 PB4，PL3 亮；放開熄 | `X3` → Y4 |
| 按 PB2，正轉 | `X1` → M0 自保持 → Y0 ON、Y4 ON |
| 按住 LS1，停止、PL1 亮、T1 計時 | `X4` 使 Y0 OFF，T0 計時，Y2 ON，Y4 OFF |
| T1 到，反轉 | `T0` → SET M1 → Y1 ON，Y4 ON，Y2 OFF |
| 放開 LS1、按住 LS2，停止、PL2 亮、T2 計時 | `X5` 使 Y1 OFF，T1 計時，Y3 ON |
| T2 到，正轉 | `T1` → RST M1 → Y0 ON，Y3 OFF，放開 LS2 |
| 重複 4～7 | 同上循環 |
| 按 PB3 停止 | `X2` → M0 OFF → Y0、Y1 OFF，M1 被 RST |
| OL 動作 | `X6` → M0 OFF，Y5 閃、Y6 斷續響 |
| 按 PB1 | M2 ON → BZ 停響、PL4 恆亮 |
| OL 復歸 | X6 OFF → M2 OFF，異常輸出全熄 |

## 五、設計說明與注意事項

1. **互鎖**：Y0、Y1 同時用輸出接點互鎖（`ANI Y1`／`ANI Y0`），實際配線時 MCF、MCR 線圈前也要串對方 b 接點做硬體互鎖。
2. **LS 必須按住**：LS1 或 LS2 在計時途中放開，T0／T1 會復歸並回到原狀態（與動作說明「此時不可放開」一致）。
3. **計時值**：`K30`＝3 秒，可依試題改成 `K50`（5 秒）等。
4. **閃爍**：原電路用 FR 閃爍電驛，PLC 以 `M8013` 取代，不需另接 FR。
5. **主電路**：MCF 與 MCR 的換相接線不變（MCR 對調任兩相），仍用硬體接線。
6. **其他機種**：FX5U 的 `M8013` 對應 `SM413`；Q／iQ-R 系列對應 `SM412`（1 秒時鐘）。
