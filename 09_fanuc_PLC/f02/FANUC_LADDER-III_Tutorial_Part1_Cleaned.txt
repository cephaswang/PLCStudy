Hello guys. Today I'm going to teach you about FANUC LADDER-III software.

Before getting into this video, we need to know what FANUC LADDER-III is and why it is used. We should know what functions we can perform with this software, so that we can use it efficiently.

The main functions of FANUC LADDER-III are:
- Input/output, display and editing of the sequence program
- Monitoring and debugging of the sequence program
- Other online settings and display of PMC parameters
- Run and stop of the sequence program
- Download and upload of the sequence program
- Writing the sequence program to flash ROM

These are the main functions available in FANUC LADDER-III.

2. WHAT IS THE PMC?
======================================================================

So, what is a PMC program? I have already made some videos about the FANUC PMC and the functions inside it. They are listed in the playlist, so you can go there and watch all of them.

What is the role of the PMC in a CNC machine? Suppose I turn on the power and I want to run my machine in JOG mode. How will the CNC know that the machine should now be in JOG mode?

Through the PMC, we send a signal to the CNC: "Hey CNC, I want to run my machine in JOG mode, so please switch to JOG mode." This job is done by the PMC.

There is no direct link between the machine's I/O signals and the CNC. We link them through the PMC, using G signals and F signals.

So I send a G signal to the CNC. The CNC identifies it: "OK, I am receiving the JOG G signal." It then switches to JOG mode and gives the confirmation.

How does the PMC know the mode has changed? The CNC tells the PMC through an F signal: "I have switched to JOG mode." After that, we can do whatever we want.

Now you understand what the PMC is and why we use it in a FANUC CNC. Let's get into the software.

5.3 SYMBOL AND COMMENT
----------------------------------------------------------------------

In Symbol & Comment we have machine signals and NC interface signals (F and G addresses), PMC parameters, and others.

Under "etc." there are many registers. The first is the machine signal X. If I select X0 to X127, we get addresses such as X0.0 to X0.7 and so on. This is the addressing format.

Here we add a symbol, a first comment and a second comment. For example, the symbol can be "START_PB" (start push button), the first comment "Start conveyor", and the second comment "Stop conveyor", or whatever you want. So for every register, you can add three kinds of identification: a symbol, a first comment and a second comment.

The same applies to the NC interface signals (F and G addresses). If you want to change a symbol, you can change it in the software.

Input/Output: If you connect the software in online mode, it shows the group, base, slot and module name. You can add comments for each. If you are working online, the software shows the name of the module and the input/output assignment. This section is used for that purpose only.

----------------------------------------------------------------------
5.4 MESSAGE
----------------------------------------------------------------------

What is Message? Here we have the A addresses (message display request bits). If you enable a message, the machine will show you an alarm. That is the main purpose of the message function.

For example, take address A0.0. Suppose I want to display "Coolant level low." Whenever A0.0 is activated, the machine displays "Coolant level low." We can then easily identify the problem: if this message is displayed, we check the program, see why the address is being activated, and refill the coolant tank. After that the machine is ready to run. This is how we use this option.

We can edit the message for every address. There are many available, from A0.0 up to A249.7. You can use as many as you need in your program.
