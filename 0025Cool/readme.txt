ST 語法，三菱 PLC


程式邏輯說明：

設備與模式

三台設備：冷卻水泵(PP)、冷卻水塔(CT)、冰水機(CH)
X_Auto_Mode 切換自動/手動

自動模式（步序控制 eStep）
啟動順序：水泵 → 確認流水開關 → 延遲5秒 → 水塔 → 延遲30秒 → 冰水機
停止順序（逆序+延遲保護）：冰水機先停 → 延遲60秒（讓冷凝器散熱）→ 水塔停 → 延遲10秒 → 水泵停

這是業界慣例（先啟動水路、後啟動壓縮機；停機時先停壓縮機、水路延遲停以保護冷凝器），若貴案場順序是「水塔先啟動」，只要對調 STEP 1/2 內容即可。

手動模式
每台設備各自有啟動/停止按鈕，但仍保留基本安全連鎖：

水塔要啟動須先確認水泵已運轉且有流水（避免空轉）
冰水機要啟動須水泵+流水+水塔都已運轉（保護冷凝器）
任一連鎖條件中斷，冰水機立即強制停機

故障處理
任一設備（水泵/水塔/冰水機）故障回授觸發，立即全部停機、重置步序、點亮警報燈。

時間設定（tPP_to_CT_PT、tCT_to_CH_PT 等）都是常數變數，可依實際現場調整。若您用的是 FX5U 系列，ST 語法支援範圍略有不同（TON 呼叫語法一致，但部分結構化元素需確認韌體版本），建議先在 GX Works3 離線編譯確認。
